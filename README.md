# 多链路融合通信项目

> 项目讨论记录与初步设计；尚未实施、采购或完成实测。更新：2026-10-29。

## 项目目标和边界

项目包含两个独立方向：
- 硬件工程：LoRa、Wi‑Fi、4G 多链路通信，依次进行地面测试、无人船和无人机部署。采用规则控制，不依赖深度学习。
- 软件研究：基于深度学习的链路选择与切换，仅在仿真中开展，以论文和专利为目标。创新性需进一步检索验证。

## 硬件方案

两条候选路径：A 为 LoRa 数传 + Wi‑Fi 图传的组合；B 为 4G 承载数传及视频。移动端采用 RK3588、摄像头、GNSS、LoRa、Wi‑Fi 网桥、4G；地面端使用电脑及对应通信设备。两端 4G 经运营商网络连接；若两端不可直接访问，可通过公网服务器中继。

### 用户提出的切换逻辑

1. 开机后两端 4G 拨号，进入低活动心跳状态；LoRa 和 Wi‑Fi 承担主要业务。
2. 远航时，超过实验测得的参考距离且 LoRa、Wi‑Fi 信号持续下降，唤醒 4G，进入并行比较。
3. 两条路径竞争 9 个数据包，记录每轮首到来源，第 10 个包到来时选择前 9 轮首到次数最多的路径；设置阈值抑制乒乓切换。9 轮均有明确获胜者时不存在平局。
4. 返航时，小于参考距离且 LoRa、Wi‑Fi 信号持续上升，切回组合路径，降低或关闭 4G 活动。

### 工程细化建议，尚待验证

- 对同编号探测消息进行重复发送、去重和首到统计。定义两条路径均超时、统计窗口上限和第十包处理方式。
- 组合路径需同时检查 LoRa 和 Wi‑Fi 的可用性，不能仅由 LoRa 探测结果代表视频质量。小包首到速度也不能单独证明视频带宽足够。
- 主路径突然失效时设置快速故障切换；恢复时连续验证两项业务，设置进入/退出阈值和保持时间。
- 4G 深度休眠、在线心跳、唤醒时延取决于具体模块；先实测再确定。视频和遥测切换需要会话、缓存、重连和去重机制，不能预先保证零中断。
- GNSS 移动端位置与固定地面端坐标计算距离；场地测试校准距离阈值。

候选设备而非最终采购定案：
- [亿佰特 E220-400T22D](https://www.ebyte.com/product/1077.html)：UART、3.3 V 信号电平，5 V TTL 有损坏风险；频率、功率及使用场景需核对，向厂家确认 RSSI 读取方式。厂家标称距离不代表现场性能，其页面声明不得用于军事及生命安全相关场景。
- [TP-LINK 室外无线网桥](https://smb.tp-link.com.cn/pages/smbcheatsheet/pages/bridge/outdoorCPE.html)：TL-S5-5KM 等定向套装可研究地面测试；移动平台的转向和载重适配需重新评估。
- [移远 EC25 系列](https://www.quectel.com/product/lte-ec25-series/)：第二个 4G 套件候选，地区版本、驱动、频段和供电需核对。

设备频率、发射功率和天线应符合测试地区规定；若在中国大陆，参考[工信部微功率设备公告](https://www.miit.gov.cn/jgsj/wgj/wjfb/art/2020/art_792ab84586c34b64bb391eb6496c0953.html)，无人机应用还需核对航空器使用条件。

## 4G 共存与地面测试

4G 可能通过射频耦合、天线接近或供电波动影响其他设备，具体需实测。以 4G 关闭、联网心跳、持续上传下载为三种状态，记录 LoRa 丢包率和时延、Wi‑Fi 视频码率及卡顿、供电电压和设备重启情况；改变天线间距、布局及供电分别排查。[移远天线共存说明](https://www.quectel.com/faqs/8-3-what-is-the-impact-if-many-modules-work-simultaneously-and-the-antennas-of-the-modules-are-very-close-to-each-other/)中的间距建议仅作参考，不代表本系统保证值。
