# 三链路并发数传基线

2026-11-20。第一阶段在地面移动场景中测量模拟遥控指令的送达和更新间隔。阿克曼底盘由原装遥控器驾驶，RK3588 在车上独立接收并记录数据。

## 收发规则

- Windows 为每轮生成实验编号，为每条模拟指令分配递增序号，并附上模拟指令值和完整性校验。LoRa、Wi-Fi 网桥和 4G 三路全程开启。每条指令的三个副本共享编号、序号和内容，各路独立提交，避免一条路阻塞其余两路。
- RK3588 持续接收三路。每收到一条有效消息，仅当该序号大于本轮已采用的最大序号才更新模拟状态。允许跳过缺号。比如先收到 103，再收到 102，模拟状态保持 103。重复与晚到副本继续入日志。
- 接收规则只比较序号。首到结果以接收端完整解析出一条有效消息时为准。RSSI 可和原始到达记录一起保存，应用层按单向发送运行。新一轮实验使用独立序号空间。
- Windows 记录每个副本是否提交给接口、提交时刻及失败原因。RK3588 记录每条链路的完整到达顺序、序号、采用结果和接收端单调时钟。副本成功提交与车端实际收到分别统计。

## 当前网页

用浏览器打开 [地面站模拟预览](../ground-station/index.html)。可以启停模拟发送、修改接口参数和发送频率、模拟断链与恢复，并在实验回放中勾选要保留的链路。「下载数据 · CSV」按所选实验导出三路完整明细，每行对应某条指令在一条链路上的副本，包含发送、接收和三路基线的处理结果。网页数据由本地模拟生成。实际硬件用[真机发包、接收和回放程序](../deploy/three-link/README.md)。

## 真机部署设计

| 位置 | 职责 |
|---|---|
| Windows 地面站 | LoRa 走指定 USB 串口，网桥走有线网络，4G 使用绑定蜂窝接口的 ECS 连接。保存发送日志，实验后合并车端日志做回放。 |
| RK3588 Ubuntu | 接收程序由 `yrt-fusion-rx.service` 管理，已设为开机自启。在三条链路上独立收包，接收明细保存在本地。 |
| Ubuntu ECS | 复用 [TCP 字节中继](../deploy/ecs-relay/README.md)。数传端口为 Windows 14550、RK3588 14551，两端主动建连。 |

实验开始前逐路核对收包来源。车端接收就绪后，在 Windows 发起新实验，再用底盘自己的遥控器开车。地面端停止发送后给在途副本留出到达时间，随后将车端日志取回 Windows。用实验编号和序号关联日志。精确单向时延需要两端时钟同步，更新空档可直接用 RK3588 的单调时钟计算。

## 室内连通复测（2026-11-20）

- Wi-Fi 网桥用于 SSH 调试。[板端重启后重新登录成功](wifi-bridge-first-test.md#rk3588-开机直连2026-11-20)。
- LoRa 使用 Windows `COM10` 和 RK3588 的 CH340 串口，参数为 `9600 8N1`，DTR 和 RTS 关闭。车端发送 `YRT-LORA-AIR-1120`，Windows 收到后回复 `YRT-LORA-GCS-1120`，板端收到完整回包。
- 4G 使用 Windows EC200A 的 RNDIS 网卡和 RK3588 的蜂窝网口，分别连接 ECS 数传端口 `14550` 和 `14551`。起初 EC200A 已注册 LTE，但 `AT+QNETDEVCTL?` 返回 `0,0,0,0`，经 RNDIS 访问公网超时。在 Windows 的 Quectel AT 口 `COM7` 执行一次 `AT+QNETDEVCTL=1,1,1`，收到 `+QNETDEVSTATUS: 1` 后，车端发送 `YRT-4G-AIR-1120`，Windows 回复 `YRT-4G-GCS-1120`，两端均收到完整消息。[移远 EC200A 拨号说明](https://forumschinese.quectel.com/t/topic/11521)

LoRa 和 4G 在同一轮复测中均通过双向短消息检查。

## 回放与验收

1. 先记录静态三路全开。验证同一序号的三份副本都能记录，模拟状态最多更新一次。构造乱序，验证状态不会退回旧序号。
2. 在地面移动路线上记录一次三路并发实验，包含直行、转弯和遮挡。再逐路断开并恢复，观察其余链路是否持续收包。
3. 用同一段车端记录和同一个观察窗口，分别回放完整三路和去掉任意一路的组合。比较采用的指令数、最长更新空档以及各链路在哪段路填补了空档。观察窗口包含首个有效更新前和末次更新后的空档，按完整原始日志确定。
4. 对回放中差异最大的组合做现场复测。离线回放沿用三路并发期间的实测记录，现场关闭链路还可能改变流量和射频共存条件。
