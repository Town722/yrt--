# 4G 与 LoRa 近距离共存实测

2026-11-06，RK3588 EC20-CE、Windows EC200A 和两台 HD-M805。保持用户布置的近距离摆位，具体天线间距未量。LoRa 频点未从实物配置读回，434 MHz 为手册默认值。

## 测得的影响

在这次静态测试中，各组 LoRa 接收 RSSI 中位数为 −26 至 −27 dBm，108 个正式测试包均得到回执。B40 板端上行相对两轮空闲，往返 P50 从 3319.7 ms 变为 3307.7 ms，P95 从 3409.5 ms 变为 3420.0 ms。两端已收包的 RSSI 中位数都保持在 −27 dBm，往返时延差处在本次短测波动范围内。

| LTE 工况 | LoRa 到地面 / 发出 | 板端收到回执 / 发出 | RTT P50 / P95，ms | 地面 / 板端 RSSI 中位数，dBm |
| --- | ---: | ---: | ---: | ---: |
| 两端 B40，无主动负载，两轮 | 24/24 | 24/24 | 3319.7 / 3409.5 | −27 / −27 |
| 板端 B40 上行约 1.50 Mbit/s，两轮 | 24/24 | 24/24 | 3307.7 / 3420.0 | −27 / −27 |
| 地面端 B40 上行 1.50 Mbit/s | 12/12 | 12/12 | 3330.3 / 3391.7 | −26 / −27 |
| 板端关闭射频，地面端 B40 保持注册 | 12/12 | 12/12 | 3266.0 / 3358.2 | −26.5 / −27 |
| 板端 B8，无主动负载 | 12/12 | 12/12 | 3330.3 / 3423.8 | −27 / −27 |
| 板端 B8 上行约 0.58 Mbit/s | 12/12 | 12/12 | 3326.4 / 3395.3 | −26 / −27 |
| 两端 B40，板端上行、地面端下行 | 12/12 | 12/12 | 3337.8 / 3403.9 | −27 / −27 |

表中的上行速率来自应用写入 TCP 的字节数和持续时间，未测 LTE 发射功率。B8 组的目标速率与 B40 相同，但实际写入速率较低。两频段对比包含载波、基站调度及上行速率差异，不能由此定量分离频段本身的影响。空闲组保持蜂窝注册，允许系统背景流量；关闭射频组只关闭板端模组。板端在 B3 限定窗口内未注册，未获得 B3 共存数据。

## 方法和数据解释

- 两端 LoRa 串口为 9600、8N1、无流控。板端每 4.5 秒发一个带序号的短帧，Windows 收到后回同序号，板端从发出至收到对应回执以单调时钟计时，回执截止为 4.3 秒。地面接收数与板端回执数分别统计。
- 对串口原始字节检查确认，测试帧换行后还有一个字节，按 HD-M805 手册的 `RSSI = 无符号字节 − 146` 换算。该值来自已解调的数据包，不能替代空闲噪声或干扰功率。约 3.3 秒的往返与两次带唤醒码的传输相符，精确模式和唤醒参数仍待读取。未把串口开销、唤醒码和无线传播拆开计时。
- 板端和地面端分别发受控 TCP 流到现有 ECS 中继，通过绑定蜂窝源地址确认传输路径。短帧和上行负载由独立程序产生。B40 空闲与板端上行交替重复两次。最后一组模拟图传方向，地面端 4G 完整收到板端通过 ECS 发送的 10,511,250 字节测试流。
- 样本规模较小。即使假设各包独立，同一工况 24 次零失败仍对应约 11.7% 的单侧 95% 丢包率上界，12 次对应约 22.1%。本次适合发现较大的退化。量化弱信号边缘的影响需在受控衰减或更长距离下重复测量，并增加每个工况的样本量。

## 频率与原因

| LTE 频段 | 与现有设备的关系 |
| --- | --- |
| B40 TDD，2300–2400 MHz | 两台模块主要注册在 EARFCN 39148，载波中心约 2349.8 MHz。板端上行和地面端上行均实测。 |
| B8 FDD，终端上行 880–915 MHz | 板端注册到下行 EARFCN 3590，对应下行中心 939 MHz，配对上行中心 894 MHz。板端空闲和上行均实测。 |
| B3 FDD，终端上行 1710–1785 MHz | 板端临时试频未注册。本次只有频段资料。 |

频率表依据 3GPP TS 36.101 第 5.5、5.7.3 节。[ETSI 标准](https://www.etsi.org/deliver/etsi_ts/136100_136199/136101/15.19.00_60/ts_136101v151900p.pdf)

如果 LoRa 实物使用手册默认的 434 MHz，B40、B8 和 B3 的 LTE 基波均与其分开。仍可能出现强信号使 LoRa 接收前端灵敏度下降，或因共用供电、地线和线束引入干扰。本次未用频谱仪、功率计或示波器，因此无法区分这些机制。Quectel 对近距离天线给出的 20 cm 以上是一般建议，具体安装需要结合布线和弱信号试验验证。[Quectel 天线共存说明](https://www.quectel.com/faqs/8-3-what-is-the-impact-if-many-modules-work-simultaneously-and-the-antennas-of-the-modules-are-very-close-to-each-other/) · [Quectel 供电设计](https://www.quectel.com/content/uploads/2024/02/Quectel_EC200AEC2x_Series_Compatible_Design_V1.0.pdf)

临时换频期间板端蜂窝设备重新枚举，改变了串口及网口编号。补测改用稳定的 USB 串口路径。试验后已核实板端恢复原频段掩码与完整功能，重新注册 B40。网络重新分配了板端蜂窝 IPv4，后续程序应从当前路由获取源地址。
