# 三链路无线质量与 LoRa 丢包复核

## 无线指标与归一化

对链路各自的实测 dBm 值 `x` 使用 `q = 1 / (1 + exp(-k × (x-m)))`。弱参考点和强参考点分别映射到 `0.1` 和 `0.9`，`m` 为两参考点的中点，`k = 2 ln(9) / (强参考点 - 弱参考点)`。固定射频输入给出同一个分数，与其他链路的强度、首到顺序无关。原始 dBm、参考点和分数都写入 CSV。初始参考点便于观察变化，后续按固定无线配置下的实际送达率校准。分数目前是无线电平的单调映射，未拟合为送达概率。

| 链路 | 车端原始指标 | 初始弱/强参考点 |
| --- | --- | --- |
| LoRa | HD-M805 包尾 RSSI，按 `原始字节 - 146` 换算。缺包尾时保留接收记录。 | −125 / −75 dBm |
| Wi-Fi 网桥 | 车端 `192.168.255.201` 的 AP-Client 对端 RSSI。只读无线状态页的一次实读为 −28。每 2 秒采样，副本关联最近 6 秒内的样本。 | −85 / −55 dBm |
| 4G | 车端 EC20 服务小区的 RSRP，附带 RSRQ 和样本年龄。2 秒采样，副本关联最近 6 秒内的样本。 | −110 / −80 dBm |

论文采用逻辑回归拟合 RSSI 与包接收率，支持使用 S 形曲线作为候选函数。LoRa 的实验证据还表明接收能力受 SNR、扩频因子、带宽和包长度约束。专利 US9769723B2 说明跨设备使用无线测量应考虑各设备的标定差异。本项目借用模型形式与独立标定原则，表中数值属于待标定的初始参考点。4G 的 RSRP 是车端到运营商服务小区的局部下行测量，整条 ECS 中转路径的送达率仍由端到端包日志统计。[RSSI 与 PRR 拟合论文](https://www.mdpi.com/1996-1073/16/11/4326) · [LoRa 接收性能实测论文](https://www.mdpi.com/1424-8220/21/4/1071) · [US9769723B2](https://patents.google.com/patent/US9769723B2/en)

## 11 月 20 日逐包复核

分母是 Windows 日志中交给 LoRa 串口的有效数据帧，分子是 RK3588 上按序号去重后的 LoRa 接收帧。发送端提交只代表本机串口接受了字节。排除 `20261120-2115`，该轮混入验证包。

| 实验 | LoRa 提交间隔中位数 | LoRa 到达/提交 | 4G 到达/提交 |
| --- | ---: | ---: | ---: |
| 2100 | 1000 ms | 13/13 | 13/13 |
| 2114 | 94 ms | 3/100 | 100/100 |
| 2116 | 94 ms | 77/112 | 未发送 4G 应用数据 |
| 2118 | 94 ms | 28/71 | 0/0，71 次 4G 提交失败 |
| 2121 | 94 ms | 62/93 | 0/0，93 次 4G 提交失败 |
| 2121-02 | 94 ms | 3/500 | 500/500 |
| 2126 | 94 ms | 3/100 | 100/100 |

`2114`、`2121-02`、`2126` 的 LoRa 均只收到序号 `1、15、16`。更强的串口投递负荷是优先解释之一，因为 20 字节每秒 10 条已等于 1.6 kbit/s 的应用负荷，高于 HD-M805 手册给出的 1.46 kbit/s 默认空速，还没计入无线开销和可能的唤醒前导。实际模组空速尚未读回。没有 4G 业务发送的几轮仍有丢包，且缺少蜂窝发射功率、LoRa RSSI、设备摆位和共同供电状态日志，无法从这些轮次分离 4G 射频贡献。应用未发送 4G 数据也不代表蜂窝射频关闭。

11 月 6 日近距离对照中，B40 空闲和板端约 1.5 Mbit/s 上行均为 `24/24`，板端 LoRa RSSI 中位数都是 −27 dBm；所有工况合计 `108/108`。这组强信号小样本没有检出明显退化，弱信号边缘和其他摆位仍需验证。如果 LoRa 处于手册默认 434 MHz，和 B40 的 2300–2400 MHz 没有同频重叠。近距离射频前端阻塞、供电或线束耦合仍可能降低灵敏度。[历史对照和逐包记录](coexistence-2026-11-06/README.md) · [ETSI LTE 频段定义](https://www.etsi.org/deliver/etsi_ts/136100_136199/136101/15.07.00_60/ts_136101v150700p.pdf) · [移远近距离天线共存说明](https://www.quectel.com/faqs/8-3-what-is-the-impact-if-many-modules-work-simultaneously-and-the-antennas-of-the-modules-are-very-close-to-each-other/)

区分两种影响时，固定位置、LoRa 参数和帧长，先在强信号和接近覆盖边缘各做一组。在每个位置交替测试 4G 关闭射频、注册空闲、固定上行负载。保持 LoRa 发送频率一致，并另做一次只改变 LoRa 发包率的实验。记录发出与收到的序号、已收包 RSSI 分布和 4G 实际上行量。副本丢失时没有包 RSSI，这些缺失仍保留在送达率的分母内。
