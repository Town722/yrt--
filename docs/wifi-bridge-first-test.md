# 数显网桥：说明书识别与首次互通测试

## 首次互通实测（2026-11-06）

Windows 的有线网口经两台网桥连到 RK3588。Windows 使用 `192.168.137.1/24`，RK3588 使用 `192.168.137.246/24`。

| 项目 | 结果 |
| --- | --- |
| SSH | Windows 从有线地址连到板端 TCP 22，读到 OpenSSH 握手标识 |
| ICMP | 12 发 12 收，往返延迟 3–5 ms，平均 3 ms |
| RK3588 → Windows 单路 TCP | Windows 绑定有线地址，完整接收 64 MiB，用时 4.63 s，约 116 Mbit/s |

以上为本次静态短测。真实视频、长时间稳定性和移动场景的吞吐量待测。

## 设备资料（2026-11-05）

实物标签为 5.8G，标称 900 Mbps，支持 DC 12 V 或 PoE 24–48 V。具体品牌、完整型号、PoE 类型及针脚和极性仍待确认。

## 从照片确认的信息

- 设备具有A/B模式拨码开关，可配置一端A、另一端B。
- 可通过按键选择数码配对编号，两端应使用一致编号。编号显示不应当作RSSI或距离。
- 说明书列出的管理地址：编号0时A为192.168.255.100、B为192.168.255.200；编号1时A为192.168.255.101、B为192.168.255.201。
- 说明书称Link指示网桥连接状态；PWR指示供电，LAN灯反映网口状态/通信。
- 图示使用PoE适配器：适配器PoE口连接网桥，LAN口连接电脑/主机。实际网桥受电口按实物标识确认。
- 纸质说明书兼有2.4 ID和5.8 ID；实物标签明确 frequency:5.8G、Speed:900Mbps。900 Mbps为标签标称值，不代表有效吞吐量。
- 实物左侧圆孔标注12V/DC；左侧RJ45下标注24V or 48V POE、1000mbps LAN；另有右侧RJ45（照片被线缆遮挡，完整用途未确认）、数码显示、A/B开关及RST。
- 实物标签写明A地址192.168.255.(100+X)、B地址192.168.255.(200+X)，X为数码显示0–F对应0–15；贴纸C10不据此确认是正式型号。
- 标签供电文字不能单独证明支持标准802.3af/at自动协商，不据此混用电源或PoE注入器。优先核对配套适配器输出及连接方式。
- 照片中管理界面的文字不够清楚，尚不能确认默认账号密码、软件读取RSSI的接口或具体无线性能。

## 当前供电安排

用户确认目前两台网桥均使用DC 12 V供电；测试时可能改用PoE，尚未确定具体PoE适配器。DC供电时，主机经网线连接网桥的数据网口即可；PoE供电时按配套适配器LAN/PoE标识连接。未确认厂家支持前，不同时接入DC与PoE电源。此记录是供电安排，不代表设备已完成互通测试。

## 拟采用的连接

每端均为：主机网口 → 配套适配器LAN口；适配器PoE口 → 网桥指定受电网口；适配器接匹配电源。
PoE口可能带电，不应误接主机网口。供电电压、极性以及主动/被动PoE类型以实物标签和对应型号资料为准。

一端A、另一端B，相同配对编号。先检查当前设置；已有连接时无需为了统一编号复位。

## 首次测试计划

1. 确认两台型号、配套供电、网口和当前A/B及编号。
2. 近距离固定摆放，按厂家要求留出间距，对准天线方向，观察PWR与Link状态。
3. 记录实际管理地址和原有网络设置。若采用编号1且设备仍是说明书默认地址，可暂将两端主机有线IPv4分别配置为192.168.255.10/24和192.168.255.20/24；这是建议测试地址，需先排除冲突。无需为纯局域网测试填写默认网关或DNS。
4. 分别打开两台实际管理地址；确认两主机可双向ping。ICMP被防火墙阻止时，仅调整相应网络配置的规则，不全局关闭防火墙。
5. 使用绑定到有线测试地址的流量测试，避免误走现有Wi-Fi或4G；再进行文件或视频传输。
6. 记录管理页能提供的信号、连接速率与统计项；程序读取方式需另查型号资料。
7. 静态互通后，再开展上车运动、供电与4G共存测试。
