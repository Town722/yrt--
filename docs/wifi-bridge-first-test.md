# 数显网桥：说明书识别与首次互通测试

记录日期：2026-11-05。依据用户提供的纸质说明书照片；未操作设备，未完成测试。具体品牌、型号、频段、额定电源和PoE类型仍待设备标签确认。

## 从照片确认的信息

- 设备具有A/B模式拨码开关，可配置一端A、另一端B。
- 可通过按键选择数码配对编号，两端应使用一致编号。编号显示不应当作RSSI或距离。
- 说明书列出的管理地址：编号0时A为192.168.255.100、B为192.168.255.200；编号1时A为192.168.255.101、B为192.168.255.201。
- 说明书称Link指示网桥连接状态；PWR指示供电，LAN灯反映网口状态/通信。
- 图示使用PoE适配器：适配器PoE口连接网桥，LAN口连接电脑/主机。实际网桥受电口按实物标识确认。
- 表中同时列有2.4 ID和5.8 ID，不足以证明已购硬件为双频设备。
- 照片中管理界面的文字不够清楚，尚不能确认默认账号密码、软件读取RSSI的接口或具体无线性能。

## 拟采用的连接

每端均为：主机网口 → 配套适配器LAN口；适配器PoE口 → 网桥指定受电网口；适配器接匹配电源。
PoE口可能带电，不应误接主机网口。供电电压、极性以及主动/被动PoE类型以实物标签和对应型号资料为准。

一端A、另一端B，相同配对编号。先检查当前设置；已有连接时无需为了统一编号复位。

## 首次测试步骤（未执行）

1. 确认两台型号、配套供电、网口和当前A/B及编号。
2. 近距离固定摆放，按厂家要求留出间距，对准天线方向，观察PWR与Link状态。
3. 记录实际管理地址和原有网络设置。若采用编号1且设备仍是说明书默认地址，可暂将两端主机有线IPv4分别配置为192.168.255.10/24和192.168.255.20/24；这是建议测试地址，需先排除冲突。无需为纯局域网测试填写默认网关或DNS。
4. 分别打开两台实际管理地址；确认两主机可双向ping。ICMP被防火墙阻止时，仅调整相应网络配置的规则，不全局关闭防火墙。
5. 使用绑定到有线测试地址的流量测试，避免误走现有Wi-Fi或4G；再进行文件或视频传输。
6. 记录管理页能提供的信号、连接速率与统计项；程序读取方式需另查型号资料。
7. 静态互通后，再开展上车运动、供电与4G共存测试。
